# 记录管理查询规则

本次复现：依据论文管理调整前后的界面与现有设计判断，整理可运行的前端查询示例。示例数据仅用于验证交互；这里的运行过程不代表历史 AI 初稿或当时的修改记录。

## 业务任务

用户需要在论文记录中定位目标记录，核对标题、关键词、作者与机构。常用词既可能出现在标题中，也可能只出现在关键词中。机构属于明确的范围条件，应与自由文本查询分开。

## 查询布局对照

原查询布局保留 ID 与名称 / 标题两个输入。ID 忽略大小写并精确匹配，名称 / 标题仅对标题做包含匹配；两个输入同时填写时取交集。用于复现已有界面的查询方式，不将其称为 AI 初稿。

统一查询布局使用一个搜索输入，覆盖标题与关键词，并提供独立的作者机构筛选。查询词先去除首尾空格并忽略大小写；标题与关键词任一包含完整查询词即匹配。查询词与机构条件取交集。不检索作者名，不通过推测补全语义。

## 交互契约

- 点击“查询”或按 Enter 后提交当前输入；编辑输入和选择机构本身不改变已经提交的结果。
- 空查询和“全部机构”返回全部示例记录。
- 重置同时清空文本、ID 和机构条件，并立即恢复全部记录。
- 切换原查询 / 统一查询布局时清空条件，防止不可见条件继续影响结果。
- 无结果时保留已填条件，提供“清空查询条件”恢复入口。
- 结果数量以实际过滤数据计算，通过可见文本与读屏状态共同反馈。
- 表格按原界面保留选择框、ID、标题、关键词、作者、作者机构与操作列。
- 表格预留稳定高度，较少结果不导致下方内容突然上移。
- 默认每页 10 条，可切换为每页 5 条；总数、页码与上一页 / 下一页均依据实际结果计算。复选框与全选作用于当前页，查询或切换记录类型后清空选择。
- 详情展示完整字段，编辑与新增保存到本次示例内存；删除需确认。弹窗支持 Escape 关闭、焦点圈定与关闭后回到触发入口。
- 批量导入使用内置的 2 条示例记录：点击“使用示例文件”查看记录摘要，再“导入示例记录”。不上传文件或访问业务接口；刷新页面恢复初始数据。

## 人工校正检查

1. 关键词检索：输入“目标检测”。统一查询返回 1 条论文记录；原查询仅查标题，返回 0 条。验证搜索范围是否按规则覆盖关键词。
2. 条件组合：统一查询输入“深度学习”，返回 3 条；加“清华大学”机构筛选后返回 1 条。
3. 提交时机：修改输入而未提交，表格仍保留上次已提交的结果。
4. 恢复路径：输入“量子芯片”返回 0 条；点击空状态中的清空按钮，恢复 6 条。
5. 原查询：ID 输入“p001”返回 P001；与标题“医疗”组合则返回 0 条。重置恢复 6 条。

## 可复用资产

记录数据采用统一结构：`id`、`title`、`keywords`、`author`、`institution`。论文与专利复用同一个 `queryResearchRecords(records, query)` 函数、表单、结果反馈和恢复逻辑，仅替换数据与页面名称。

“专利记录”是本次复用演示，不表示历史项目已经完成这次复用。切换记录类型时清空条件并恢复 6 条。专利搜索“深度学习”同样返回 3 条，筛选“清华大学”后返回 1 条。

此规则可以作为后续记录管理页的设计输入。若实际业务需要新增字段、权限、远程分页或模糊分词，应先明确规则并补充对应的人工校正检查。
