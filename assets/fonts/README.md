# Homepage name fonts

The name font is a renamed subset that retains the original copyright and SIL Open Font License 1.1 metadata. Produced with fontTools 4.68.0 and Brotli 1.2.1.

## English: Portfolio Name Script

- Source: [Nothing You Could Do](https://github.com/google/fonts/tree/main/ofl/nothingyoucoulddo), from the official Google Fonts repository blob `5ff49fb944e0df19d6a68dea53d2c43c69141e77`.
- Source TTF SHA-256: `1daf8cf79076bf59c5a9117b5efd6ecea35e57a05ef127fe4f95b072b8a5245d`.
- Output: `portfolio-name-script.woff2`, 1,320 bytes.
- Characters: the name `Leo Li` including its space.
- License: `OFL-nothingyoucoulddo.txt`.

Only `Leo Li` uses this face. The Chinese name, introductory prefix, role, supporting copy, and other site content use the existing sans-serif stack. This subset is not suitable for arbitrary copy.

The Chinese fine-pen candidate is retained only in `artifacts/首屏字体调整-2026-11-13/` for the local comparison. It is not used by the homepage.
